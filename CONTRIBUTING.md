# Contributing to TaylorDB

We welcome contributions from the community. If you would like to contribute to TaylorDB, please follow these guidelines:

## Getting Started

To get started, you will need to fork the repository and clone it to your local machine. Then, you can install the dependencies and run the tests to make sure everything is working correctly.

```bash
git clone https://github.com/your-username/taylordb.git
cd taylordb
npm install
npm test
```

## Submitting a Pull Request

When you are ready to submit a pull request, please make sure to do the following:

- **Write tests**: Make sure to write tests for your changes. We use Jest for testing, so you can add your tests to the `__tests__` directory.
- **Update the documentation**: If you are adding a new feature, please make sure to update the documentation to reflect your changes.
- **Follow the coding style**: We use Prettier to format our code, so please make sure to run `npm run format` before submitting your pull request.

## Code of Conduct

Please note that we have a [code of conduct](CODE_OF_CONDUCT.md) that we expect all contributors to follow. Please make sure to read it before contributing.
