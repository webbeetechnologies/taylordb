    Class QueryBuilder<DB, TableName, Selection, LinkName>

    The main query builder class for constructing and executing select queries.

    Type Parameters

    • DB extends AnyDB

      The database type.

    • TableName extends keyof DB

      The name of the table to query.

    • Selection = object

      The type of the selected fields.

    • LinkName = null

      The name of the link field if this is a subquery.

    with

    • with<
          const TArg extends
              string
              | readonly (LinkColumnNames<DB[TableName]> & string)[],
      >(
          relations: TArg,
      ): QueryBuilder<
          DB,
          TableName,
          ResolveWithPlain<DB, TableName, TArg, Selection>,
      >

      Includes related records from a linked table. This method has two overloads:

      1. Pass an array of link field names to include all fields from the related records.
      2. Pass an object to specify subqueries for each link field.

      Type Parameters

      • const TArg extends string | readonly (LinkColumnNames<DB[TableName]> & string)[]

      Parameters

      • relations: TArg

        The relations to include.

      Returns QueryBuilder<DB, TableName, ResolveWithPlain<DB, TableName, TArg, Selection>>

      A new QueryBuilder instance with the specified relations included.

      Example

      const usersWithPosts = await qb
        .selectFrom('users')
        .select(['id', 'name'])
        .with(['posts']) // Assuming 'posts' is a link field on the 'users' table
        .execute();

      Example

      const usersWithPublishedPosts = await qb
        .selectFrom('users')
        .select(['id', 'name'])
        .with({
          posts: (qb) => qb.select(['title', 'content']).where('isPublished', '=', true),
        })
        .execute();
