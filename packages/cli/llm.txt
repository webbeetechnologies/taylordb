# @taylordb/cli — LLM Documentation Index

This package is the command-line interface for TaylorDB. Its primary purpose for developers is generating a runtime `taylorSchema` object and inferred TypeScript `TaylorDatabase` type from a live TaylorDB app so they can be used with the query builder.

## Documentation

- [Type Generation](./docs/type-generation.md)
  How to run `taylordb generate-schema`, what arguments it accepts, what runtime schema is produced (`taylorSchema` with field helpers), how `TaylorDatabase` is inferred with `InferTaylorDatabase`, how select options and plugin types are emitted, and what the output file looks like.
