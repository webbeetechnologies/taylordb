# TaylorDB — LLM Documentation Index

TaylorDB is a managed database platform. This monorepo contains the official TypeScript tooling published as separate npm packages. Each package ships its own `llm.txt` and `docs/` directory.

## Packages

### @taylordb/cli
Command-line interface. Connects to a live TaylorDB app and generates a strongly-typed TypeScript schema file for use with the query builder.

- [Package LLM index](./packages/cli/llm.txt)
- [Type Generation](./packages/cli/docs/type-generation.md)

---

### @taylordb/query-builder
Fluent, type-safe query builder. Requires the types generated by the CLI.
The built-in `collaborators` table exposes `id`, `name`, `emailAddress`, `avatar`, `status`, and `searchText`; `status` is text with expected values `ACTIVE` or `INACTIVE`.
Exports existing builder helper types such as `Insertable`, `Updatable`, `Filters`, `FiltersSet`, `FieldWithDirection`, `LimitOffset`, `PaginationRequest`, `ColumnNames`, aggregation result helpers, and plugin action inference helpers from `@taylordb/query-builder`.
